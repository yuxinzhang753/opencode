Swiss Fertility: A Correlation Analysis

Associations among socio-economic indicators in Swiss districts

1 Introduction

The classic Swiss fertility data describe 47 French-speaking districts of Switzerland around 1888. Each district is characterised by six quantitative measures: fertility, the proportion of males in agriculture, the results of a military examination, education, the percentage of Catholics, and infant mortality.

This document loads the data directly from a remote CSV, computes the Pearson correlation matrix among the numeric variables, and displays it as an annotated heatmap.

2 Load the data

3 Correlation matrix

We correlate every numeric column with every other. The leading District column is dropped first so that only quantitative variables enter the matrix.

Code 
swiss_num <- swiss %>%
  select(where(is.numeric))

corr_mat <- cor(swiss_num, use = "complete.obs")
round(corr_mat, 2) %>%

4 Annotated correlation heatmap

Each cell is coloured by the correlation coefficient and labelled with its value, so the plot can be read without consulting a separate legend of numbers.

Code 
# Preserve the matrix's variable ordering on both axes
var_levels <- colnames(corr_mat)

corr_df <- as.data.frame(corr_mat) %>%
  mutate(Variable1 = factor(rownames(corr_mat), levels = var_levels)) %>%
  pivot_longer(
    cols = -Variable1,
    names_to = "Variable2",
    values_to = "r"
  ) %>%
  mutate(Variable2 = factor(Variable2, levels = var_levels))

ggplot(corr_df, aes(x = Variable2, y = Variable1, fill = r)) +
  geom_tile(color = "white", linewidth = 1) +
  geom_text(aes(label = sprintf("%.2f", r)), size = 4.2, family = "mono") +
  scale_fill_gradient2(
    low    = "#2166AC",
    mid    = "white",
    high   = "#B2182B",
    midpoint = 0,
    limits = c(-1, 1),
    name   = "Pearson r"
  ) +
  coord_fixed() +
  labs(
    title    = "Correlation heatmap of Swiss district indicators",
    subtitle = "Blue = negative association, red = positive association",
    x = NULL,
    y = NULL
  ) +
  theme_minimal(base_size = 13) +
  theme(
    axis.text.x  = element_text(angle = 45, hjust = 1, face = "bold"),
    axis.text.y  = element_text(face = "bold"),
    panel.grid   = element_blank(),
    plot.title   = element_text(face = "bold")
  )

5 Interpretation

  • Fertility and education are strongly negatively correlated: districts with more schooling tended to have lower fertility.
  • Fertility and Catholic show a clear positive association, while agriculture is negatively related to education and examination results.
  • Infant mortality is largely disconnected from the socio-economic indicators: its correlations with agriculture, examination, and education are all within \(\pm 0.11\) of zero. Its one notable association is a moderate positive link with fertility (\(r = 0.42\)).

Correlation does not imply causation, and these are district-level (ecological) quantities, so the coefficients should be read as descriptive summaries of association rather than as causal effects.
